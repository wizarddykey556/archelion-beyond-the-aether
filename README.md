# ARCHELION: BEYOND THE AETHER

**An original space-opera / science-fantasy tabletop roleplaying game currently in development.**

## Public Development Notice

**Project title:** ARCHELION: BEYOND THE AETHER  
**Format:** Tabletop Roleplaying Game  
**Genre:** Space Opera / Science Fantasy  
**Status:** In active development  
**Established development title:** September 2026  
**Public development record:** 29 September 2026

**ARCHELION: BEYOND THE AETHER** is an independent original tabletop roleplaying game and setting currently in development.

The project is being built around cinematic science-fiction adventure, tactical roleplaying, distinct character classes and species, advanced technology, and extraordinary phenomena arising from a setting in which the **Aether** is a fundamental part of reality.

Within the setting, civilisation's growing understanding of the Aether led to the discovery of a brilliant phenomenon known as **Arclight**. The development of the **Arclight Engine** made the first interstellar crossing possible and opened an era in which civilisation moved beyond its first star: **the Archelion Age**.

The title **ARCHELION: BEYOND THE AETHER** identifies this original game project and its associated fictional setting.

This repository exists as a public development record. It intentionally contains only a high-level description of the project; unpublished rules, mechanics, setting material, class designs, species designs and other development material are maintained separately while the game is in development.
